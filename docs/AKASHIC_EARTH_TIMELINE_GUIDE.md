## 🎮 QUICK START

### 1. Launch the System
```bash
# From Universal_Being directory
godot --path . scenes/AKASHIC_EARTH_TIMELINE_MONITOR.tscn
```

### 2. Basic Controls
- **WASD**: Move your plasmoid around Earth
- **Arrow Keys**: Orbit camera around Earth
- **Mouse Wheel**: Zoom in/out
- **Click UI Panels**: Add events to timeline

### 3. First Actions
1. **Add a TikTok Video**: Paste URL, give it a title, hit "ADD VIDEO"
2. **Log a Disaster**: Select type, set intensity, add location
3. **Create Reality Edit**: Write your symbolic intervention

## 🌐 THE EARTH GLOBE

### What You See
- **Blue Sphere**: Earth with consciousness glow
- **Red Dots**: Disaster events (size = intensity)
- **Cyan Squares**: Videos/social media posts
- **Yellow Orbs**: Consciousness events
- **Timeline Spiral**: Events arranged around Earth in time

### Location System
- **Format**: `latitude,longitude,altitude`
- **Example**: `40.7,-74.0,0` (New York City)
- **Range**: Lat (-90 to 90), Lon (-180 to 180), Alt (0+)

## 📱 TIKTOK/VIDEO INTEGRATION

### Adding Videos
1. **Get URL**: Copy TikTok, YouTube, or social media URL
2. **Paste in Field**: "TikTok/Video URL" input
3. **Add Title**: Brief description of content
4. **Set Location**: Where was this filmed/relevant?
5. **Click "ADD VIDEO"**

### What Happens
- Video gets **consciousness level** (1-10) based on content
- **Timeline position** calculated from upload/add time
- **Reality impact score** estimated from viral potential
- **3D marker** appears on Earth globe

### Consciousness Analysis
The system analyzes video titles/tags for keywords:
- **"awakening", "consciousness"** = Higher levels
- **"spiritual", "meditation"** = Mid levels  
- **"love", "peace", "wisdom"** = Consciousness boost
- **Level 7+** = May create timeline branch

### Disaster Types

- **Social**: war, pandemic, cyber_attack
