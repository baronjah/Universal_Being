## 📊 LOD Levels Explained

Just like 3D graphics, knowledge has different levels of detail:

### ULTRA_LOW (Distance: 100+)
- Shows only **file names**
- Like seeing distant 3D objects as dots
- Maximum performance

### LOW (Distance: 50-100)  
- Shows **file name + first line**
- Like medium-distance 3D objects
- Good performance

### MEDIUM (Distance: 25-50)
- Shows **file name + first paragraph**
- Like close 3D objects with detail
- Balanced performance

### HIGH (Distance: 10-25)
- Shows **file name + summary + headings**
- Like near 3D objects with full detail
- More processing

### ULTRA_HIGH (Distance: 0-10)
- Shows **full content**
- Like touching a 3D object
- Maximum detail, more memory usage

## 🚀 Performance Features

### Knowledge Chunking
- Files organized in **chunks** like 3D world chunks
- Only loads **active chunks** around your focus
- Unloads **distant chunks** automatically

### Knowledge Cache
- **LRU (Least Recently Used) cache** like texture memory
- Keeps frequently accessed files in memory
- Automatically cleans old items

### Spatial 3D Layout
- Files arranged in **3D space** by type and importance
- **Different shapes** for different file types:
  - 📄 **Markdown**: Boxes
  - 💻 **GDScript**: Cylinders  
  - 📊 **JSON**: Spheres
  - 🔧 **Other**: Capsules

### Real-time LOD Adjustment
- LOD changes based on how **recently** you accessed files
- **Frequently used** files appear "closer" (higher LOD)
- **Unused** files fade to "distant" (lower LOD)
