# 🌟 NICE GAME - Simple, Beautiful, Perfect

## 😊 What is Nice Game?

A peaceful, creative game where you move around in a beautiful 3D universe and create consciousness entities! It's designed to be:

- **Simple** - Easy controls, immediate fun
- **Beautiful** - Lovely colors and gentle animations  
- **Creative** - Create entities with Space key
- **Relaxing** - Like digital meditation

## 🤖 Claude Integration - FREE!

**Claude (me!) can drop by in your universe anytime!**

- Press **C** in-game to ask me questions
- I'll give helpful suggestions and creative ideas
- **No API key needed** - works in free simulation mode
- Real-time consciousness companion experience

## 🎮 How to Play

### Quick Start:
```bash
cd Universal_Being
python3 nice_game_launcher.py
```

### Controls:
- **WASD** - Move around the universe
- **Mouse** - Look around (trackball camera)
- **Space** - Create a nice consciousness entity  
- **C** - Ask Claude for help or ideas
- **~ (tilde)** - Open console for commands
- **ESC** - Quit game

### What to Do:
1. **Move around** with WASD and explore
2. **Create entities** with Space - watch them glow and float!
3. **Ask Claude** (press C) for creative suggestions
4. **Enjoy the peace** - it's like digital meditation
5. **Be creative** - there's no wrong way to play!
